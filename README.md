# Gaming Database Backend Web Services

## Project Overview
This is a group project for Birmingham City University, developed as part of our Computer Science coursework.

The aim is to create a gaming database system where users can browse games, manage their personal game collections, leave reviews and interact with other users.

## Technologies Used
- **Python** – Backend development
- **Flask** – REST API development
- **SQLite** – Database management
- **Git & GitHub** – Version control and group collaboration
- **Bruno** – API testing

## Main Features
- User registration and login
- Browse and search games
- Add games to personal collections
- Rate and review games
- Follow other users
- Manage favourites and view activity

## Group Collaboration
Each group member works on their assigned features using Git and GitHub.

To contribute:
1. Pull the latest changes from GitHub.
2. Create a branch for your feature.
3. Write and test your code.
4. Commit and push your changes.
5. Create a pull request to merge your work into the main branch.
